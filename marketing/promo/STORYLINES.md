# Storylines

The film is about 30 seconds, 1920 × 1080, English, silent. Its one thing: _you can host your own draw-and-guess game, without ads_. The spine is one real game: Mara draws a lighthouse, three friends guess it.

## A. Guess it first (built)

The feature as the hook, told as an object-to-object chain. The film opens inside a drawing that is already growing while wrong guesses pile up next to it; the right guess ends the turn, and only then does the game say its name.

- First two seconds: white paper fills the frame, a striped tower is half drawn, "a tower?" lands beside it.
- Beats: `guesses on paper → the turn ends in the real interface → Kritzel → a link fills the lobby → phone and desktop → four languages → no ads → the podium → end card`
- Look: the game's own paper and marker colours; white paper for titles, the dark interface as footage.
- Sound: none, as requested.

## B. Friday, 16:55

A moment in someone's day. A team chat asks "anyone up for a round?", the usual answer is a site full of banners, and the reply is a single command that starts a private game.

- First two seconds: a clock at 16:55 and a chat message arriving.
- Beats: `the question → the banners → one command → the link in the chat → the game → the podium → end card`
- Look: a desk and a chat window. It needs interfaces that are not Kritzel's, which would have to be drawn.
- Sound: none.

## C. One command

The bold one, as an endless zoom. A terminal fills the frame, `docker run` is typed, and the camera dives through the address it prints into the lobby, through the canvas into the drawing, through the drawing into the podium.

- First two seconds: a prompt and the first characters of the command.
- Beats: `the command → the address → the lobby → the canvas → the guess → the podium → end card`
- Look: one dark terminal world. The first seconds show typing and nothing of the game.
- Sound: none.

## Why A

It is the only one that is real footage almost from the first frame to the last, and a stranger understands the game before reading a word.
